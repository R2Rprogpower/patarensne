# Узел обнаружения киевских Telegram-чатов

## Назначение

Узел собирает максимально полный **обнаруженный** список публичных групп, связанных с Киевом. Абсолютную полноту гарантировать нельзя: Telegram не публикует каталог всех групп, результаты глобального поиска ограничены, а поисковики индексируют только часть `t.me`.

## Входы

### Словарь запросов

`config/queries-kyiv.txt` содержит варианты города, районов и тематик на украинском, русском и английском. Одна строка — один запрос, строки с `#` игнорируются.

### Ручной импорт

Поддерживаются:

- TXT — ссылки могут находиться в любом месте текста;
- CSV — распознаются колонки `url`, `link`, `telegram` или `username`, а также необязательные `title`, `name`, `description`, `about`.

### Telegram

Telethon вызывает ограниченный глобальный `contacts.Search` под отдельной пользовательской сессией. Узел не вступает в найденные группы.

### Веб-поиск

Опциональный SearXNG выполняет `site:t.me <запрос>`. Это заменяемый бесплатный провайдер; код не зависит от HTML конкретного Google/Bing.

## Нормализация и дедупликация

- `telegram.me` приводится к `t.me`;
- регистр username нормализуется;
- ссылки на сообщения превращаются в ссылку на группу;
- `t.me/s/...` нормализуется;
- публичные ссылки дедуплицируются по URL;
- invite-ссылки фиксируются как `private`, но не открываются и не используются для вступления.

## Проверка Telegram

Для публичного username узел получает доступные метаданные и сохраняет:

- название и описание;
- `group`, `channel`, `user` или `unknown`;
- `open`, `approval_required`, `private`, `channel`, `not_group`, `unavailable`;
- число участников, если Telegram его возвращает;
- время последней проверки.

Каналы остаются в полном CSV для аудита, но не попадают в TXT для Activity Scanner.

## Киевский скоринг

Скоринг использует `config/kyiv-terms.json`:

- прямое упоминание города в названии — сильный сигнал;
- упоминание в описании или username — средний сигнал;
- район в названии — сильный локальный сигнал;
- исходный поисковый запрос — только слабый сигнал.

Порог экспорта по умолчанию — `4`. Кандидат, найденный только по запросу «Київ», но не имеющий подтверждения в собственных метаданных, не проходит автоматически.

## Выходы

`telegram-results.csv` содержит:

```text
url;username;title;description;entity_type;access_status;members_count;kyiv_score;kyiv_reasons;sources;source_queries;discovered_at;checked_at
```

`telegram-results.txt` содержит по одной ссылке на строку и предназначен для первого узла.

## Что делать дальше

Периодический запуск добавит новые ссылки и перепроверит известные. Следующий безопасный этап — обход публичных ссылок из описаний уже проверенных групп. Чтение сообщений для расширения графа следует добавлять отдельно, с лимитами и без сохранения текста.

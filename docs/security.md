# Безопасность и ограничения

## Секреты

К секретам относятся:

- токен управляющего бота;
- Telegram API ID и API hash;
- пользовательская MTProto-сессия;
- пароль двухфакторной аутентификации.

Они вводятся только локально, не передаются в чат, не записываются в команды и не коммитятся. Каталог данных должен быть доступен только владельцу компьютера.

Если сессия передаётся отдельным защищённым пакетом, импортировать следует только
Telethon `*.session` и локальные параметры API по
[инструкции](session-migration.md). Остальное содержимое приложению не нужно.
Сессию разрешено использовать только с подтверждённого согласия владельца
аккаунта и в рамках согласованной read-only задачи.

Второй узел использует те же Telegram API ID/hash и отдельную MTProto-сессию. Команда `auth` принимает номер, код входа и 2FA-пароль через скрытый локальный ввод. Значения не логируются и не передаются параметрами командной строки.

## Минимизация данных

Для отчёта нужны только идентификаторы авторов в памяти на время подсчёта. Тексты сообщений, имена пользователей и содержимое медиа в итоговой базе не сохраняются.

## Ограничения доступа

- управляющий бот использует allowlist владельцев;
- публичный HTTP-сервер и webhook не нужны;
- контейнеру не публикуются входящие порты;
- отчёты отправляются только владельцу задания;
- session-файл не включается в архивы отчётов.

Docker Compose второго узла:

- не публикует входящие порты;
- не публикует SearXNG на хост: он доступен только в Compose-сети, но сохраняет исходящий доступ к поисковикам;
- удаляет Linux capabilities и включает `no-new-privileges`;
- запускает приложение с read-only root filesystem;
- монтирует для записи только локальный `data/` и временный `/tmp`.

## Ограничения Telegram

- всегда соблюдать `FloodWait`;
- не запускать сотни запросов параллельно;
- не обходить заявки и приватные ссылки;
- не вступать в группы автоматически;
- не отправлять сообщения;
- при ограничении аккаунта остановить задания до окончания указанного Telegram срока.

Глобальный поиск Telegram и поисковики не дают полного каталога. Формулировка результата — «максимально полный обнаруженный список на дату запуска».

## Запрещённые расширения

В проект намеренно не входят:

- поиск списка чатов по username человека;
- сбор или продажа графа членств пользователей;
- автоматическое вступление, заявки, инвайты и рассылки;
- обход приватных групп;
- извлечение базы стороннего бота через автоматизированное истощение его лимитов.

## Точность метрик

Число уникальных авторов приблизительное: анонимные администраторы и публикации от имени группы могут иметь общий идентификатор. Удалённые сообщения и недоступная история не учитываются.

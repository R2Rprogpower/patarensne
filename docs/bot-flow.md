# Пользовательский интерфейс бота

## Новый отчёт

1. Пользователь отправляет `/scan`.
2. Бот просит прикрепить `.txt` со ссылками.
3. После загрузки бот сообщает число строк и уникальных ссылок.
4. Кнопками предлагает период: `Сегодня`, `24 часа`, `3 дня`, `7 дней`.
5. Показывает подтверждение и запускает задание.

## Прогресс

Бот редактирует одно служебное сообщение, чтобы не засорять чат:

```text
Проверено: 347 / 1000
Доступно: 301
По заявке: 18
Недоступно: 28
```

Обновление прогресса должно происходить не чаще одного раза в 15–30 секунд.

## Результат

После завершения бот отправляет:

1. короткую сводку;
2. полный CSV;
3. JSON для последующей машинной обработки.

Пример сводки:

```text
Проверено: 1000
Активных по заданным критериям: 214
По заявке: 73
Недоступных: 41
```

## Доступ

Бот отвечает только заранее разрешённым Telegram user ID. Сообщения остальных пользователей игнорируются и фиксируются без содержимого присланных файлов.

## Отмена и восстановление

- `/cancel` ставит текущему заданию статус отмены после завершения текущего API-запроса;
- `/status` показывает сохранённый прогресс;
- после перезапуска локального узла незавершённое задание продолжается автоматически;
- `/last` повторно отправляет последний готовый отчёт.
